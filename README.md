# 온라인 폐지줍기 - 티끌모아 태산

v0 디자인 개선용 웹 시제품입니다. **모든 행사·정답·포인트·참여 기록은 가상 데이터입니다.** 실제 서비스 코드 전체의 저장소가 아니라, 외부 디자인 검토를 위해 분리한 홈페이지 결과물입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치·계정·API 키가 필요 없습니다.

- 오늘의 이벤트: 게시판, 정답, 상세 펼치기, 참여 상태 선택
- Npay: 리스트, 제목 검색, 포인트 정렬
- 참여 통계: 일간·주간·월간·연간, 상세 내역, 가상 CSV

화면 선택과 기록은 메모리에서만 동작하며 새로고침하면 초기화됩니다. 실제 광고 클릭·응모·계정 조회·예약 작업은 없습니다.

## v0에서 디자인 개선

`V0_PROMPT.txt`를 요청문으로 사용하고 `screenshots/`의 세 이미지를 참고 자료로 첨부합니다. 결과물을 기존 앱에 적용할 때에는 기존 기능과의 연결을 별도로 검증해야 합니다.

## 디자인 시안 v1 기준

- **글꼴**: 시스템 한글 고딕 1종 (`Pretendard → Apple SD Gothic Neo → Malgun Gothic`). 외부 폰트 로드 없음. 크기 12 / 13 / 14(본문) / 16 / 22(제목)px, 최소 12px.
- **색상**: 배경 `#f4f5f1`, 표면 `#fff`, 본문 `#1b2a23`, 보조 `#5f6c65`(대비 5.6:1), 브랜드 `#17463b`, 주의 `#fdf1d8`/`#7a5208`, 마감 임박 `#b4401f`. 모두 `design.css`의 `:root` 토큰.
- **간격**: 4px 단위(4·8·12·16·20·24·32), 모서리 6px(컨트롤)·10px(카드).
- **컴포넌트**: 상태 탭(밑줄형+건수), 세그먼트(유형·기간), 버튼 3종(primary·outline·ghost), 표시 칩(중립·주의).

### 화면별 변경점

- **오늘의 이벤트**: 열 머리글이 있는 게시판형. 마감은 D-day+날짜, 3일 이내 강조. 정답은 `Q번호 · 보기번호 · 답안` 칩으로 항상 표시. 상세 조건과 참여 상태 선택을 한 줄에 배치. 변경된 행은 좌측 선으로 표시하고, 저장 바는 하단 고정(변경 0건이면 비활성). 유형 버튼(전체·퀴즈·간단 응모)을 실제 필터로 동작시킴.
- **Npay**: 제목·포인트·적립 링크 3열. 목록 머리에 건수·합계 한 줄 요약(배너 아님). 완료 탭은 버튼 대신 완료 배지+날짜.
- **참여 통계**: 4개 요약 카드에 해당 기간 범위 표기. "완료 기준 적립액" 가정 문구를 카드 바로 아래에 고정. 내역은 행 아래로 펼쳐지는 하위 표.
- 사이드바의 큰 문구 영역을 제거하고 메뉴에 남은 건수 배지를 추가. 모바일(760px 이하)은 상단 가로 메뉴로 전환.

### 기존 앱 반영 시 주의점

- `mock-data.js`의 `answer`는 문자열 → `[{ q, no, text }]` 배열로 변경. 실제 API가 문자열이면 변환 함수를 두거나 문자열 그대로 칩 1개로 표시.
- 외부 링크 클릭은 참여완료 처리하지 않음(기존 원칙 유지). Npay의 5초 자동 닫기·보관 확장 연결은 변경하지 않았으므로 기존 버튼 클래스/핸들러를 새 `.btn-outline`에 다시 연결.
- Npay 정렬 유지는 사본에서 메모리만 사용. 실제 앱의 localStorage 저장 로직을 `state.npaySort`에 연결.
- 클래스명이 전면 변경됨(`board-*`, `npay-quick-card` 등 → `event-*`, `npay-row`). 기존 CSS와 섞지 말고 교체 후 회귀 확인.

실제 참여 기록·쿠키·토큰·개인정보·서버 환경설정·Chrome 확장은 포함하지 않았습니다. 자세한 구성은 `README.txt`, 최초 패키지 점검 범위는 `VALIDATION.txt`를 참고하세요.
