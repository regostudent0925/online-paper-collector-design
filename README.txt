v0 업로드용 디자인 패키지
작성일: 2026-10-16 (한국시간)

사용 순서
1. ZIP을 풀어 index.html을 브라우저로 열면 디자인 사본이 실행됩니다.
2. v0에 ZIP을 첨부하고 V0_PROMPT.txt 내용을 입력합니다.
3. ZIP 안 이미지가 자동 참조되지 않으면 screenshots의 JPG 3개를 따로 첨부합니다.
4. 원하는 결과의 코드와 스크린샷을 기존 개발 채팅으로 가져와 적용·회귀 검증을 진행합니다.

파일
- index.html: 3개 화면의 HTML
- design.css: 현재 앱의 화면 스타일을 재사용한 디자인 CSS
- mock-data.js: 독립 작성한 가상 행사·포인트·참여 이력
- design.js: 외부 연결 없는 화면용 JavaScript
- screenshots/01-today.jpg: 오늘의 이벤트
- screenshots/02-npay.jpg: Npay 목록
- screenshots/03-statistics.jpg: 참여 통계
- V0_PROMPT.txt: v0 요청문
- VALIDATION.txt: 확인 범위 및 패키지 점검 결과

사본 동작
- 사이드 메뉴, 이벤트 상태 탭·검색·상세 펼치기·가상 선택 저장
- Npay 상태 탭·제목 검색·정렬
- 통계 기간 전환·상세 내역·가상 CSV 저장
- 일반 이벤트의 유형 버튼은 시각적 예시이며 실제 유형 필터는 생략
- 선택은 메모리에만 저장되며 새로고침 시 초기화
- 적립/참여 버튼은 안내문만 표시하고 외부 사이트를 열지 않음
- 실제 앱의 API·영구 저장·확장·스케줄을 포함하지 않음

데이터 경계
실제 앱의 state/data 폴더, 참여 기록, 금액 합계, 쿠키, 토큰, 브라우저 프로필, 개인정보, 환경설정, Chrome 확장, 서버 소스는 포함하지 않았습니다.
이 패키지는 외부 서비스에 업로드할 수 있도록 준비한 파일이며, 작성 과정에서 v0 업로드·계정 연결·유료 결제·외부 공개 배포를 수행하지 않았습니다.

모든 행사·주최사·문항·답안·금액·날짜는 가상 예시입니다. 실제 행사 참여에 사용하지 마세요.
