첨부한 ZIP의 코드와 screenshots 폴더의 3개 이미지를 바탕으로 개인용 이벤트·포인트 관리 홈페이지의 디자인을 개선해 주세요.

사이트명: 온라인 폐지줍기 - 티끌모아 태산

이 자료는 외부 디자인 검토를 위해 독립 작성한 가상 화면입니다. 실제 행사·계정·참여 이력·개인정보·적립액은 포함하지 않았습니다. 코드의 화면 구조와 동작을 참고하되, 숫자와 내용은 예시로 취급해 주세요.

목표
- 매일 이벤트를 빠르게 훑고 직접 참여한 뒤, 기록과 포인트 합계를 확인하는 도구
- 한국어 가독성, 효율적인 공간 사용, 적은 클릭
- 깔끔하고 차분하며 일관된 색상·글꼴·버튼·간격
- PC와 모바일 반응형
- 커다란 소개 배너와 조사·참여 요약 배너를 추가하지 않기
- 긴 제목을 읽을 수 있게 줄바꿈하고 포인트·행동 버튼 정렬
- 키보드 조작·포커스 표시·명확한 레이블·충분한 대비 유지

1. 오늘의 이벤트: screenshots/01-today.jpg
- 참여가능 / 참여완료 / 참여의사없음 탭 유지
- 게시판형으로 이벤트명, 경품·선정 방식/인원, 마감, 참여 방식, 참여 링크 표시
- 로그인·가입·앱·자격 제한·조건 확인 필요 등 핵심 표시를 짧게 유지
- 퀴즈 정답은 접지 않고 바로 표시. 번호와 답안 내용을 함께 표시
- 개인정보·필수 동의·자격·중복 참여·정답 근거는 상세 펼치기로 확인
- 참여 상태 선택과 저장 버튼 유지
- 외부 링크 클릭만으로 일반 이벤트를 참여완료 처리하지 않음

2. Npay 클릭·방문 적립: screenshots/02-npay.jpg
- 참여가능 / 참여완료 탭 유지
- 제목, 포인트, 적립 링크만 있는 간결한 리스트
- 제목 검색, 포인트 높은 순 정렬, 실제 목록 갱신 시각
- 실제 앱은 기본 높은 순이며 선택한 정렬을 브라우저에 유지함
- 사본에서는 외부 광고를 열거나 실제 완료 처리하지 않음
- 실제 앱의 사용자가 포인트 받기를 누른 뒤 5초에 닫고 자동 보관하는 확장 연결은 기존 기능이다. 이번 디자인 단계에서는 구현하거나 변경하지 않음

3. 참여 통계: screenshots/03-statistics.jpg
- 오늘 / 이번 주 / 이번 달 / 올해 요약
- 일간 / 주간 / 월간 / 연간 참여 내역, 항목별 펼치기, CSV 저장
- 이벤트 건수, Npay 완료 건수, 완료 기준 적립액 구분
- 완료 표시 포인트가 지급되었다고 가정한 합계임을 명확히 유지
- 한국시간, 주간 월요일~일요일 기준
- 이 ZIP의 통계·내역·날짜는 모두 가상

기술 요청
- 현재 실제 앱은 일반 HTML/CSS/JavaScript와 별도 로컬 Node 서버로 동작
- 가능하면 일반 HTML/CSS/JavaScript로 디자인 결과 제공
- React/Next.js 등으로 제작하면 디자인 구성과 스타일을 별도 정리하고 필요한 변환 사항을 설명
- 화면과 디자인용 동작만 작성. 실제 로그인·계정 연동·잔액 조회·광고 클릭·자동응모·개인정보 입력·제출·스케줄·외부 배포는 하지 않기
- 데이터와 화면 코드를 분리하고 가상 데이터만 사용
- 기능을 임의로 삭제하지 말고 변경안과 이유를 설명
- 먼저 일관된 디자인 시안 1개를 제안한 뒤 피드백을 받아 조정

받고 싶은 결과
세 화면 미리보기, 디자인 코드, 모바일 대응, 색상·글꼴·간격 기준, 기존 앱 반영 시 주의점.
